# auto-clicker-76

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

`auto-clicker-76` is a lightweight, high-frequency automation tool built in Python for seamless mouse macro execution. Designed for precise click rates and minimal CPU overhead, it gives users complete control over automated input sequences using global hotkeys.

## Features

- **High-Precision Timing:** Microsecond-level interval accuracy delivering up to 1,000 clicks per second.
- **Global Hotkey Listeners:** Non-blocking background keybindings to start, pause, or instantly kill the clicking thread.
